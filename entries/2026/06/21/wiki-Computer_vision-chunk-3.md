## Computer Vision Applications

This page covers the broad range of practical applications where computer vision is deployed, spanning industrial inspection, medicine, military systems, autonomous vehicles, tactile sensing, and more. It distinguishes between computer vision (core automated image analysis technology) and machine vision (computer vision combined with other methods for industrial automation).

## Key Concepts

- **Computer vision vs. machine vision**: Computer vision is the general field of automated image analysis; machine vision specifically refers to its application in industrial settings combined with other automation technologies.
- **Learning-based methods** are increasingly replacing pre-programmed solutions across application domains.
- **3D shape generation/reconstruction** from single or multi-view depth maps and silhouettes is an active area enabled by deep learning.
- **Market size (2024)**: Industry ($5.22B), Medicine ($2.6B), Military ($996.2M) — these are the three leading sectors.
- **Medical computer vision**: Extracts diagnostic information from image data — tumor detection, arteriosclerosis, organ measurement, blood flow analysis, dental pathology, and image enhancement (ultrasound, X-ray noise reduction).
- **Machine vision in manufacturing**: Quality control / defect detection (especially wafer inspection in semiconductor manufacturing), robotic pick-and-place guidance, and optical sorting in agriculture.
- **Military applications**: Target detection, missile guidance (area-based targeting with local image-based target selection), battlefield awareness via multi-sensor fusion.
- **Autonomous vehicles**: Spans submersibles, ground vehicles, aerial vehicles, and UAVs. Uses computer vision for navigation, SLAM, obstacle detection, and task-specific event detection (e.g., forest fire detection).
- **Tactile feedback**: Rubber/silicon sensors with embedded strain gauges or cameras provide surface micro-undulation detection and robotic hand calibration.

## Relationships

- **Deep learning** — enables 3D shape reconstruction and increasingly underpins all CV application areas.
- **SLAM (Simultaneous Localization and Mapping)** — core technique for autonomous vehicle navigation.
- **Vision transformers** — used in agricultural monitoring (e.g., strawberry disease detection at 98.4% accuracy).
- **MediaPipe** — Google's open-source framework bridging CV models to edge device deployment (face detection, image classification, object detection).
- **Optical sorting** — machine vision application in agricultural processing.
- **Activity recognition / visual surveillance** — event detection applications of CV.
- **Augmented reality** — relies on CV for 3D surface/plane tracking.
- **Medical image processing** — specialized subfield connecting CV to diagnostic medicine.

## Exam-Relevant Points

- Know the distinction between **computer vision** (general image analysis) and **machine vision** (industrial automation applications).
- **Three largest CV market sectors (2024)**: Industry > Medicine > Military.
- **Wafer inspection** is one of the most prevalent machine vision applications in manufacturing.
- **Autonomous vehicles** use CV for: navigation, SLAM, obstacle detection, and event detection.
- **Medical CV** applications include both diagnostic extraction (tumors, measurements) and image enhancement (noise reduction in ultrasound/X-ray).
- **Missile guidance** systems use area-based targeting with local image-based target selection upon arrival — a two-phase approach.
- **Tactile sensing** via silicon-embedded cameras with point markers enables robotic hand calibration — an example of CV extending beyond traditional 2D image analysis.
- **Learning-based methods** are displacing pre-programmed approaches across all application areas.
- **Multi-sensor fusion** (combining image sensors with other data sources) is key to military "battlefield awareness" concepts.
