## Empirical Risk Minimization and SVM Properties

This page explains how support vector machines can be understood through the lens of empirical risk minimization (ERM), connecting SVMs to a broader family of statistical inference algorithms. It also covers SVM properties, parameter selection strategies, and known limitations.

## Key Concepts

- **Expected risk** ε(f) = E[ℓ(y, f(X))] is the ideal quantity to minimize, but requires knowing the joint distribution of (X, y), which is typically unknown.
- **Empirical risk** ε̂(f) = (1/n) Σ ℓ(yₖ, f(Xₖ)) approximates expected risk using training data; minimizing it is the ERM strategy.
- **ERM convergence**: Under assumptions (e.g., data generated by a finite Markov process) and a sufficiently small hypothesis space, the empirical risk minimizer converges to the expected risk minimizer as n grows.
- **Tikhonov regularization** constrains the hypothesis space by adding a penalty R(f) = λ‖f‖, preferring simpler hypotheses. The regularized objective becomes: f̂ = argmin [ε̂(f) + R(f)].
- **Hinge loss**: ℓ(y, z) = max(0, 1 − yz). The soft-margin SVM is ERM with hinge loss plus Tikhonov regularization (‖w‖²).
- **Target functions** — the function minimizing expected risk for each loss:
  - Square loss → conditional expectation E[yₓ]
  - Logistic loss → logit function ln(pₓ / (1 − pₓ))
  - Hinge loss → optimal classifier f*(x) directly (outputs ±1 based on whether pₓ ≥ 1/2)
- The hinge loss target function recovers *only* the optimal classification decision, not the full distribution of y|x — this is a feature, not a limitation, as it means SVMs converge to the simplest correctly-classifying function.
- SVMs are **maximum margin classifiers**: they simultaneously minimize empirical classification error and maximize geometric margin.
- SVMs are generalized linear classifiers and can be seen as extensions of the perceptron, or as a special case of Tikhonov regularization.

## Commands and Syntax

- **SVM objective function**: minimize [1/n Σ max(0, 1 − yᵢ(wᵀx − b))] + λ‖w‖²
- **Parameter selection via grid search**: use exponentially growing sequences, e.g., λ ∈ {2⁻⁵, 2⁻³, …, 2¹³, 2¹⁵} and γ ∈ {2⁻¹⁵, 2⁻¹³, …, 2¹, 2³}
- Evaluate each (λ, γ) combination using cross-validation; select best; retrain on full training set with chosen parameters.
- **Bayesian optimization** is an alternative to grid search that often requires evaluating far fewer parameter combinations.

## Relationships

- **Hinge loss vs. other losses**: SVM (hinge), regularized least-squares (square loss), and logistic regression (log-loss) are all ERM + Tikhonov regularization — they differ only in loss function choice.
- **Perceptron**: SVMs extend the perceptron with margin maximization and kernel methods.
- **Tikhonov regularization**: SVMs are a special case; the regularization term controls model complexity and ensures well-posedness.
- **Kernel methods**: The choice of kernel (e.g., Gaussian/RBF with parameter γ) determines the hypothesis space richness and directly affects SVM convergence properties.
- **Multi-class problems**: SVMs are inherently binary classifiers; multi-class tasks require reduction strategies (e.g., one-vs-one, one-vs-all).

## Exam-Relevant Points

- The soft-margin SVM is equivalent to ERM with hinge loss and Tikhonov (L2) regularization.
- The hinge loss target function is exactly the Bayes-optimal classifier f*, unlike square loss (conditional expectation) or log-loss (logit), which estimate the full conditional distribution.
- SVMs are also known as maximum margin classifiers because they simultaneously minimize classification error and maximize geometric margin.
- SVM hyperparameters (kernel choice, kernel parameters like γ, regularization λ) are typically selected via grid search with cross-validation or Bayesian optimization.
- Key SVM limitations: requires fully labeled data, produces uncalibrated probabilities, is natively binary-only, and has difficult-to-interpret parameters.
- The regularization penalty R(f) ensures the optimization problem is well-defined and favors simpler hypotheses.
- In a sufficiently rich hypothesis space (appropriate kernel), SVM converges to the simplest function that correctly classifies the data — this extends the geometric max-margin interpretation.
